Judge 1

Theory: Reference catalogues are executable, source-cited ORM declarations whose import relationships establish dependencies and whose creation calls should tolerate reruns. The loader replays this catalogue into the domain apps rather than owning its own data model.

Instead of: A versioned reconciliation system would use stable identifiers and authoritative updates; these scripts mostly seed rows and relations through get_or_create.
