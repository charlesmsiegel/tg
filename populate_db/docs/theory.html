Theory: The package is the shipped World of Darkness reference catalogue, loaded through scripts whose exports also connect dependent records. One pilot catalogue now expresses permanent identity and authoritative scalar data in JSON while retaining its historical Python exports.

Instead of: It is maintained seed content for the application, rather than an arbitrary import/export framework; existing script dependencies and object exports remain part of its practical interface.
