Judge 1

Theory: The characters app models World of Darkness characters as a polymorphic core character/human hierarchy extended by gameline-specific models, forms, views, and progression services. Creation and advancement are stateful workflows whose common mechanics live in core bases and whose variants are selected by type registries.

Instead of: A data-driven rules engine with gamelines as configuration; this code chooses Django model inheritance and explicit Python variants so each ruleset can carry bespoke behavior.
