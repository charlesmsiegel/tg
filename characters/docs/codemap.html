characters — orientation

Characters are typed World of Darkness sheets with inherited traits, ordered creation tasks and gameline-specific spending rules. Creation and advancement alter the same persistent character through registered workflows and services.

Character changes cross two separate state machines

Advance a creation task

sequenceDiagram
  participant V as Creation view
  participant T as advance
  participant W as Workflow
  participant DB as Character row
  V->>T: advance(character, user)
  T->>T: Check unfinished status and EDIT_FULL
  alt denied
    T-->>V: PermissionDenied
  else allowed
    T->>W: Resolve current position and skip predicates
    T->>DB: Apply skip effects and save new position atomically
    T-->>V: New position
  end
  • Caller form saves and terminal submission remain outside this navigation helper: characters/chargen/transitions.py:22.
  • Stored positions are ordinals; inserting a task requires migrating unfinished sheets: characters/chargen/workflow.py:3.

Spend XP through a locked concrete sheet

sequenceDiagram
  participant C as Spending caller
  participant F as Service factory
  participant DB as Character row
  participant S as Gameline service
  C->>F: locked(character)
  F->>DB: Atomic select for update and refresh
  F->>S: Choose service by character type
  C->>S: spend(category, example, value)
  alt unknown category or validation failure
    S-->>C: XPSpendResult failure
  else valid category
    S->>S: Registered category handler in transaction
    S-->>C: XPSpendResult
  end
