Judge 3

Theory: A chained selection is modeled as a parent-child relation declared on Django form fields, validated again on the server, and rendered by a self-contained widget that either embeds a choice tree or asks an AJAX choice provider. The form class is the source of truth from which chain metadata and callbacks are discovered.

Instead of: It does not require every application to hand-code JavaScript and endpoints; it favors convention-based form introspection and automatic widget configuration, including dynamic form import for zero URL setup.
