Theory: A chronicle is a shared tabletop world whose player-owned polymorphic objects pass through creation, scoped permission checks and storyteller approval. Game-line-specific rules refine these objects, while reference catalogues supply reusable world vocabulary. Fresh databases use live models and legacy databases receive guarded schema patches.

Instead of: This is a campaign record and approval system rather than a universal rules engine: its game-line models and explicit workflows encode particular rules and preserve existing play state.
