Authorization has an adapter layer and one policy evaluator

Ordinary project HTTP callback

sequenceDiagram
  participant D as Django resolver
  participant M as AuthorizationMiddleware
  participant P as authorize_route
  participant V as Target view
  D->>M: process_view with callback and arguments
  M->>M: Validate object ID and private game audience
  alt hidden or malformed ID
    M-->>D: Fixed 404
  else project callback
    M->>P: Evaluate declared route policy
    alt no declaration or denied
      P-->>D: Denial or PermissionDenied
    else permitted
      P-->>M: None
      M->>V: Continue dispatch
    end
  end
  • Unknown declarations fail closed: core/access_policy.py:53. ACTION policy itself only checks method/login; action classes must authorize their subject: core/access_policy.py:59.
  • Private game record lookup is intentionally adapted before policy checks to avoid ID disclosure: core/middleware/authorization.py:70.

Registry-built object page

sequenceDiagram
  participant M as Middleware
  participant R as RegistryViewMixin
  participant DB as Polymorphic ORM
  participant P as authorize_route
  participant V as Custom or generic view
  M->>R: Delegate registry authorization
  R->>DB: Resolve detail or update subject once
  alt object absent
    R-->>M: Http404
  else object present
    R->>P: Evaluate policy with resolved subject
    alt denied
      P-->>R: Safe response or exception
    else permitted
      R->>V: Dispatch and reuse subject
    end
  end
  • The wrapper must run before custom view logic: core/model_registry.py:72.
  • Nested reality-zone fields require an extra permission-filtered queryset; this domain exception sits in generic form construction: core/model_registry.py:123.

Data and boundary ownership

Shared querysets select chronicle audiences (core/models.py:53), while game-specific private audiences are adapted in middleware (core/middleware/authorization.py:53). Registry form construction also filters reality-zone querysets (core/model_registry.py:123). These are concrete domain dependencies in infrastructure, not an acyclic generic framework.

Validated model saves centralize one write guard, but skip_validation is an escape hatch (core/base.py:22). Services in other apps remain responsible for multirow transactional invariants.
