Theory: The core app models the cross-domain laws shared by characters, items, locations, and chronicles: polymorphic object identity, validation, URLs, permissions, reusable view behavior, cache behavior, and common reference data. Instead of: A thin utilities package with each domain owning its policy; the current code centralizes invariants and access policy to keep the three object families behaviorally aligned.
